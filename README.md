# Student Performance & CGPA Classification Model

## 📌 Project Overview
This repository contains a data processing and machine learning workflow designed to analyze student academic performance. Using custom student datasets (tracking features like Roll Numbers, Student Names, and CGPA), the project demonstrates how to clean, structure, and utilize tabular data for predictive modeling.

## 🛠️ Tech Stack & Tooling
* **Language:** Python 3
* **Environment:** Google Colab
* **Machine Learning Library:** Scikit-Learn (`sklearn`)
* **Data Manipulation:** Pandas (`pandas`)
* **Algorithm Implemented:** Decision Tree Classifier (`DecisionTreeClassifier`)

## 📊 Core Workflow & Implementation
* **Data Synthesis:** Programmatically generated a balanced dataset modeling student records, structural attributes, and CGPA brackets.
* **Model Training:** Utilized Scikit-Learn to segment training and evaluation sets using `train_test_split`.
* **Evaluation:** Implemented structural evaluation loops using `accuracy_score` metrics to track classifier validity.
